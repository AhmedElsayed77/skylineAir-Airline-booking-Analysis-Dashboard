# ✈️ Skyline Air Booking Analysis Dashboard

## 📌 Overview
This project presents a comprehensive data analysis of airline booking behavior, developed in collaboration with Skyline Air.  
The goal is to extract meaningful insights from booking data to support better business decisions in the aviation industry.

---

## 🎯 Objectives
- Analyze customer booking behavior
- Identify trends in flight demand and scheduling
- Evaluate sales channel performance
- Understand passenger preferences and service needs
- Build an interactive dashboard for decision-making

---

## 📊 Key Insights

### 🌍 Global Passenger Distribution
- Identified high-demand regions based on booking origins
- Highlighted geographic concentration of customers
- Suggested potential markets for expansion

### 📅 Booking Trends
- Detected peak booking days across the week
- Analyzed booking volume patterns to optimize operations

### ⏳ Purchase Lead Analysis
- Compared booking lead time across:
  - OneWay
  - RoundTrip
  - CircleTrip
- Revealed differences in customer planning behavior

### 📱 Sales Channel Performance
- Internet bookings dominate over mobile
- Conversion rates vary by channel

### 🧳 Passenger Preferences
- 66% of passengers request extra services (e.g., baggage)
- Opportunity for upselling and revenue growth
